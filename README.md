# IoT-Smart-Speed-Measurement
# نظام قياس السرعة الذكي (IoT Smart Speed Measurement)

يعتمد هذا المشروع على دمج المكونات الإلكترونية (Arduino) مع تقنيات إنترنت الأشياء (IoT) عبر منصة Node-RED لإنشاء نظام متكامل لقياس سرعة الأجسام وإطلاق إنذارات سحابية. تم تطوير هذا المشروع كمتطلب لمقرر الأنظمة المدمجة في جامعة الرازي.

## الميزات الرئيسية (Features)
* **حساب السرعة لحظياً:** استخدام حساسين للأشعة تحت الحمراء (IR Sensors) لقياس الزمن المستغرق وحساب السرعة بدقة.
* **الإنذار المحلي:** عرض القراءات على شاشة LCD، وإطلاق تنبيه صوتي (Buzzer) تلقائياً عند تجاوز السرعة المحددة (60 كم/ساعة).
* **التنبيهات السحابية:** توجيه البيانات عبر المنفذ التسلسلي إلى Node-RED، وإرسال رسائل تحذيرية فورية إلى الهواتف الذكية عبر (Telegram Bot API).
* **المراقبة عن بُعد (Dashboard):** عرض السرعة المباشرة عبر بروتوكول MQTT على تطبيق الجوال (MQTT Dash)، مع توفير مسار HTTP GET لاستعلام السرعة عبر متصفح الويب.
* **معالجة متقدمة للأخطاء:** فلترة برمجية في Node-RED لتجاهل الأخطاء الرياضية الناتجة عن حجب الحساسات ومنع انهيار النظام.

## المكونات (Hardware Requirements)
* Arduino Uno
* 2x IR Sensors (حساسات أشعة تحت الحمراء)
* I2C LCD Display (شاشة عرض)
* Buzzer (جرس إنذار)
* أسلاك توصيل ولوحة تجارب (Breadboard)

## البرمجيات (Software & Tools)
* Arduino IDE (لبرمجة المتحكم بلغة C++)
* Node-RED (لإدارة تدفق البيانات والربط السحابي)
* MQTT Broker (لنقل البيانات إلى تطبيق الجوال)
* Telegram Bot API (لإرسال الإشعارات)
